ИНСТРУКЦИЯ ПО ЗАПУСКУ САЙТА:

1. Распакуй этот архив на компьютер.
2. Положи свои видеоролики в папку assets/ и назови их:
   - work1.mp4, work2.mp4, work3.mp4 (для вертикальных Reels/Shorts)
   - horizontal1.mp4, horizontal2.mp4 (для горизонтальных видео)
3. Открой файл index.html через Блокнот (или любой редактор кода) и замени:
   - YOUR_USERNAME на свой никнейм в Telegram
   - тексты кейсов и ссылки на свои проекты
4. Загрузи все файлы и папку assets в свой новый репозиторий на GitHub (Add file -> Upload files).
